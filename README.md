# y-gui (Archived)

>
> Please visit [https://github.com/luohy15/y-agent](https://github.com/luohy15/y-agent) for the actively maintained successor.

---

A web-based graphical interface for AI chat interactions with support for multiple AI models and powerful MCP (Model Context Protocol) integrations. Beyond standard chat capabilities, y-gui leveraged MCP to connect with Gmail, Google Calendar, image generation services, and more.
